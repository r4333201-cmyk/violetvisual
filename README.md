# Violet Visual — Fabric 1.21.11 (клиентский визуал)

Сборка: открой папку в IntelliJ IDEA (JDK 21), дождись импорта Gradle, затем `./gradlew build`.
Готовый jar: `build/libs/violetvisual-1.0.0.jar` → в папку `.minecraft/mods` (нужен Fabric API).

Если нет gradlew: скопируй папку `gradle/` и файлы `gradlew`, `gradlew.bat` из официального
fabric-example-mod (ветка 1.21.11) или создай проект по шаблону на https://fabricmc.net/develop/template/
и перенеси в него `src/`.

Управление: Right Shift — меню, C (удерживать) — зум. Конфиг: `config/violetvisual.json`.
